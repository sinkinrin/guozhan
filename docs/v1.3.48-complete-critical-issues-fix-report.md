#### **🔴 问题3修复 - CoreManager战争调度器重用问题**

**问题根因**：
- `CoreManager.canAttackCore` 方法每次点击都创建新的 `WarEventScheduler()` 实例
- 导致 `isWarTime()` 始终返回 `false`，护盾在真实战争窗口期间仍然阻止核心伤害

**修复方案**：

```kotlin
// 旧代码：val warScheduler = cn.lcofficial.guozhan.task.WarEventScheduler()
// 新代码：使用 Guozhan.instance.warScheduler
if (!Guozhan.instance.warScheduler.isWarTime()) {
```

**修复文件**：`src/main/kotlin/cn/lcofficial/guozhan/manager/CoreManager.kt`

#### **🔴 问题2修复 - 核心摧毁后视觉效果未删除**

**问题根因**：
- 当核心血量归零后，核心的视觉效果（信标和保护玻璃）仍然存在于世界中
- 缺少删除核心视觉效果的逻辑

**修复方案**：
在 `onCoreDestroyed()` 方法中添加RegionScheduler任务删除视觉效果：
- 删除中心信标（Material.BEACON）
- 删除周围的保护玻璃（3x3x3立方体，除中心外的所有Material.GLASS方块）
- 使用RegionScheduler确保在正确的线程中执行方块操作

**修复文件**：`src/main/kotlin/cn/lcofficial/guozhan/manager/CoreManager.kt`

#### **🔴 问题1修复 - Squaremap地图颜色标识错误**

**问题根因**：
- 地图上会出现国家的颜色错误标识
- 缺少国家固定颜色机制，每次都动态生成颜色

**修复方案**：
1. **数据库层面**：在 `Countries` 表中添加 `mapColor` 字段
2. **数据模型层面**：在 `Country` 类中添加 `mapColor` 属性
3. **业务逻辑层面**：实现 `getOrGenerateMapColor()` 方法生成固定颜色
4. **地图集成层面**：修改 `SquaremapIntegration` 使用固定颜色

**核心逻辑**：
- 基于国家ID的哈希值生成稳定的随机颜色
- 使用HSB颜色空间确保颜色鲜艳明亮
- 颜色生成后立即持久化到数据库
- 地图集成直接使用国家的固定颜色

**修复文件**：
- `src/main/kotlin/cn/lcofficial/guozhan/data/Country.kt`
- `src/main/kotlin/cn/lcofficial/guozhan/manager/CountryManager.kt`

#### **🟡 问题4修复 - 自动税收时间戳同步问题**

**问题根因**：
- `TaxCollectionTask.kt` 中的自动税收更新 `country.lastAutoTaxTime`
- 但从不刷新 `TaxSystem.taxPolicies` 中的时间戳
- 手动 `/tax collect` 仍然看到旧的时间戳，允许立即进行第二次收税

**修复方案**：
1. 在 `TaxSystem.kt` 中添加 `updateLastCollectionTime()` 方法
2. 在自动税收和手动税收完成后都调用此方法同步时间戳
3. 确保 `taxPolicies` 缓存与数据库状态保持一致

**修复文件**：
- `src/main/kotlin/cn/lcofficial/guozhan/task/TaxCollectionTask.kt`
- `src/main/kotlin/cn/lcofficial/guozhan/economy/TaxSystem.kt`

#### **🟡 问题5修复 - 护盾过期检查的额外调度器跳转**

**问题根因**：
- `ShieldManager.checkExpiredShields` -> `deactivateShield` 流程中
- 异步查询已经在全局调度器上返回结果，但 `deactivateShield` 又调度了另一个全局任务
- 额外的跳转将护盾移除延迟了一个tick，并使错误处理复杂化

**修复方案**：
1. 修改 `deactivateShield()` 方法，添加 `useScheduler` 参数
2. 在 `checkExpiredShields()` 中直接执行护盾停用逻辑
3. 避免额外的GlobalRegionScheduler调度，提升性能

**修复文件**：`src/main/kotlin/cn/lcofficial/guozhan/manager/ShieldManager.kt`
