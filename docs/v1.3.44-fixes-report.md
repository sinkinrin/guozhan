### 1. 修复上贡功能的国库资源更新问题 ✅

**问题描述**:
- 玩家使用上贡功能时，背包中的物品正确减少
- 但国库资源（金币/钻石）没有正确增加
- 上贡功能总是显示成功，但实际资源没有添加到国家对象中

**根本原因**:
- `EconomyManager.contributeResource()` 方法的两阶段执行逻辑正确
- 但缺少详细的日志记录来追踪问题
- 可能存在数据库保存时机问题

**修复方案**:
1. **增强日志记录**: 在 `contributeResource()` 方法中添加详细的调试日志
   - 记录上贡前后的国库状态
   - 记录计算的资源增加量
   - 记录数据库保存操作
   - 向玩家显示当前国库状态

2. **修复线程安全问题**: 在 `distributeResources()` 方法中发现并修复了线程安全问题
   - 原方法在主线程中直接修改 Country 对象
   - 修复为使用 GlobalRegionScheduler 包装状态修改
   - 添加原子性资源检查，防止竞态条件

**修复代码**:
```kotlin

cn.lcofficial.guozhan.Guozhan.instance.logger.info("🔧 [上贡] 上贡前国库状态 - 金币: $oldGold, 钻石: $oldDiamond")
cn.lcofficial.guozhan.Guozhan.instance.logger.info("🔧 [上贡] 计算的资源增加 - 金币: +${data.goldIncrease}, 钻石: +${data.diamondIncrease}")

// 更新国家资源

country.diamond += data.diamondIncrease

cn.lcofficial.guozhan.Guozhan.instance.logger.info("🔧 [上贡] 更新后国库状态 - 金币: ${country.gold}, 钻石: ${country.diamond}")
```

### 2. 新增GM战争管理功能 ✅

**功能需求**:
为管理员提供快速管理战争状态的工具，用于测试和紧急情况处理。

**实现功能**:

#### 2.1 一键开启战争功能
```
/u gm startwar <攻击国家> <防守国家>
```

**功能特性**:
- ✅ 立即开启指定两个国家之间的战争
- ✅ 跳过战争准备阶段，直接进入战争状态
- ✅ 设置战争开始时间为当前时间
- ✅ 广播战争开始消息（带GM标识）
- ✅ 完整的参数验证（国家存在性、重复战争检查）
- ✅ 详细的操作日志记录
- ✅ 权限控制：`guozhan.admin.gm`

#### 2.2 一键结束战争功能
```
/u gm endwar <攻击国家> <防守国家> [胜利方]
```

**功能特性**:
- ✅ 立即结束指定两个国家之间的战争
- ✅ 支持指定胜利方或平局结束
- ✅ 自动应用战争奖励机制：
  - 调用 `WarEffects.applyVictoryEffects()` 为胜利方玩家发放奖励
  - 调用 `WarEffects.applyDefeatEffects()` 为失败方玩家应用惩罚
  - 更新战争统计数据
- ✅ 广播战争结果消息
- ✅ 清理战争状态和相关数据
- ✅ 权限控制：`guozhan.admin.gm`

**实现代码示例**:
```kotlin
/**
 * GM命令：一键开启战争
 * 🔧 v1.3.44: 新增GM战争管理功能
 */
private fun gmStartWar(sender: CommandSender, attackerName: String, defenderName: String) {
    // 参数验证
    val attackerCountry = CountryManager.getByName(attackerName) ?: return
    val defenderCountry = CountryManager.getByName(defenderName) ?: return
    
    // 检查战争状态
    if (WarManager.isAtWar(attackerCountry, defenderCountry)) {
        sender.sendWarning("已经处于战争状态")
        return
    }

    // 🔧 v1.3.44: 使用GlobalRegionScheduler确保线程安全
    cn.lcofficial.guozhan.util.run {
        try {
            // 使用WarManager的GM模式开启战争
            WarManager.startWarGM(attackerCountry, defenderCountry)
            
            // 记录GM操作日志
            cn.lcofficial.guozhan.Guozhan.instance.logger.info("🔧 [GM战争] 管理员 ${sender.name} 手动开启战争：${attackerCountry.name} vs ${defenderCountry.name}")
            
            sender.sendSuccess("§c[GM模式] §f已成功开启战争！")
        } catch (e: Exception) {
            sender.sendError("开启战争时发生错误: ${e.message}")
        }
    }
}
```

**权限配置**:
- `guozhan.admin.gm` - 允许使用所有GM命令
- `guozhan.admin.gm.startwar` - 允许开启战争（可选细分权限）
- `guozhan.admin.gm.endwar` - 允许结束战争（可选细分权限）

**使用示例**:
```bash
# 开启战争
/u gm startwar 大明 大清

# 结束战争（平局）
/u gm endwar 大明 大清

# 结束战争（指定胜利方）
/u gm endwar 大明 大清 大明
```
