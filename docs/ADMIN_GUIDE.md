# GuoZhan插件管理员指南

## 概述

本指南为GuoZhan插件的服务器管理员提供详细的GM命令使用说明，特别是新增的战争管理和时间限制绕过功能。

## GM命令权限系统

### 权限节点结构
```
guozhan.admin.*              # 所有GM权限（推荐给OP）
├── guozhan.admin.use        # 基础GM命令使用权限
├── guozhan.admin.give       # 物品给予权限
├── guozhan.admin.country    # 国家管理权限
├── guozhan.admin.economy    # 经济管理权限
├── guozhan.admin.territory  # 领土管理权限
├── guozhan.admin.teleport   # 传送权限
├── guozhan.admin.debug      # 调试权限
├── guozhan.admin.reload     # 重载权限
├── guozhan.admin.data       # 数据管理权限
├── guozhan.admin.war        # 战争管理权限 (新增)
└── guozhan.admin.shield     # 护盾管理权限 (新增)
```

## 战争管理命令

### 1. 手动触发战争
```
/gzgm startwar <国家1> <国家2>
```

**功能**: 立即在两个国家之间触发战争，绕过时间限制（原本只能在周六19:20-22:00）

**权限**: `guozhan.admin.war`

**示例**:
```
/gzgm startwar 大明 大清
```

**特点**:
- ✅ 绕过周六时间限制
- ✅ 立即生效，无需等待
- ✅ 包含[GM模式]标识
- ✅ 记录到GM操作日志
- ✅ 全服广播通知

### 2. 手动结束战争
```
/gzgm endwar <国家1> <国家2>
```

**功能**: 立即结束两个国家之间的战争

**权限**: `guozhan.admin.war`

**示例**:
```
/gzgm endwar 大明 大清
```

**特点**:
- ✅ 强制结束战争
- ✅ 更新外交关系为敌对
- ✅ 包含[GM模式]标识
- ✅ 记录操作者信息
- ✅ 全服广播通知

### 3. 查看战争状态
```
/gzgm warinfo
```

**功能**: 查看当前所有活跃的战争状态

**权限**: `guozhan.admin.war`

**显示信息**:
- 战争双方国家名称
- 战争持续时间
- 战争ID（用于调试）
- 活跃战争总数

## 护盾管理命令

### GM护盾激活
```
/gzgm shield <国家> <小时>
```

**功能**: 强制为指定国家激活护盾，绕过王战时间段限制

**权限**: `guozhan.admin.shield`

**参数**:
- `<国家>`: 目标国家名称
- `<小时>`: 护盾持续时间（1-72小时）

**示例**:
```
/gzgm shield 大明 24
```

**特点**:
- ✅ 绕过王战时间段限制
- ✅ 仍需检查其他条件（资源、冷却等）
- ✅ 包含[GM模式]标识
- ✅ 记录到GM操作日志
- ✅ 全服广播通知

## 时间限制绕过机制

### 原有时间限制
1. **护盾激活**: 王战时间段（周六19:20-22:00）内无法激活
2. **战争宣战**: 只能在周六19:20-22:00时间段内宣战
3. **其他功能**: 部分功能可能有时间限制

### GM模式绕过
- **战争管理**: `/gzgm startwar` 可在任何时间触发战争
- **护盾管理**: `/gzgm shield` 可在王战时间段激活护盾
- **标识显示**: 所有GM操作都会显示`[GM模式]`标识
- **日志记录**: 所有绕过操作都会记录到GM日志

## 使用场景

### 测试场景
```bash
# 测试战争系统
/gzgm startwar 测试国1 测试国2

# 测试护盾在王战时间的表现
/gzgm shield 测试国1 1

# 查看当前战争状态
/gzgm warinfo

# 结束测试战争
/gzgm endwar 测试国1 测试国2
```

### 紧急处理
```bash
# 紧急结束失控的战争
/gzgm endwar 国家A 国家B

# 为受攻击国家紧急激活护盾
/gzgm shield 受攻击国 12
```

### 活动组织
```bash
# 为特殊活动手动触发战争
/gzgm startwar 红队 蓝队

# 活动结束后清理战争状态
/gzgm endwar 红队 蓝队
```

## 安全注意事项

### 权限分配建议
- **完全信任的管理员**: `guozhan.admin.*`
- **活动组织者**: `guozhan.admin.war`
- **技术支持**: `guozhan.admin.shield`

### 操作记录
- 所有GM操作都会记录到日志文件
- 包含操作者、时间、目标、参数等信息
- 建议定期检查GM操作日志

### 最佳实践
1. **测试优先**: 在测试服务器验证命令效果
2. **通知玩家**: 重要操作前通知相关玩家
3. **记录原因**: 在操作日志中记录操作原因
4. **及时清理**: 测试完成后及时清理测试数据

## 故障排除

### 常见问题

**Q: 战争无法启动**
A: 检查国家名称是否正确，确保两个国家都存在且不是同一个国家

**Q: 护盾激活失败**
A: 检查国家资源是否足够，是否在冷却期内

**Q: 权限不足**
A: 确保拥有对应的权限节点，检查权限插件配置

### 调试命令
```bash
# 开启调试模式
/gzgm debug on

# 查看国家详细信息
/gzgm info <国家名>

# 关闭调试模式
/gzgm debug off
```
