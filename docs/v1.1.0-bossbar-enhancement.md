# BossBar核心血量显示系统增强

## 📋 功能概述

基于 ROADMAP v1.1.0 的规划，对现有的 BossBar 核心血量显示系统进行增强，使其更符合原始需求并提升用户体验。

## 🎯 改进目标

### 当前问题分析
1. **显示逻辑不完整** - 当前只显示给核心附近50格内的敌对玩家，不符合"双方国家所有成员"的需求
2. **性能问题** - 遍历世界所有玩家计算距离，在大型服务器上性能较差
3. **缺少战争状态检查** - 没有验证是否处于战争或敌对状态
4. **配置选项缺失** - 缺少可配置的显示范围、样式等选项
5. **错误处理不足** - 缺少异常处理和边界情况处理

### 改进方案

#### 1. 显示逻辑优化
- **双方国家成员显示** - 攻击核心时，被攻击国家和攻击者国家的所有在线成员都能看到 BossBar
- **战争状态验证** - 只在战争或敌对关系下显示给敌方
- **智能显示管理** - 根据玩家位置和状态动态管理显示

#### 2. 性能优化
- **缓存机制** - 缓存国家成员列表，减少数据库查询
- **异步处理** - 将 BossBar 更新操作异步化
- **智能更新** - 只在必要时更新 BossBar

#### 3. 配置系统
- **显示范围配置** - 可配置的显示距离和条件
- **样式配置** - 可配置的颜色、样式、标题格式
- **性能配置** - 可配置的更新频率和缓存时间

## 🔧 技术实现方案

### 1. 配置文件扩展
在 `config.yml` 中添加 BossBar 相关配置：

```yaml
# BossBar 配置
bossbar:
  # 是否启用 BossBar 显示
  enabled: true
  # 显示范围（格）
  display-range: 100
  # 更新频率（tick）
  update-interval: 20
  # 标题格式
  title-format: "{country} 核心血量"
  # 是否显示给攻击者国家
  show-to-attacker-country: true
  # 是否显示给被攻击国家
  show-to-defender-country: true
  # 缓存时间（秒）
  cache-duration: 30
```

### 2. BossBar 管理器增强

#### 新增数据结构
```kotlin
data class BossBarConfig(
    val enabled: Boolean = true,
    val displayRange: Int = 100,
    val updateInterval: Long = 20L,
    val titleFormat: String = "{country} 核心血量",
    val showToAttackerCountry: Boolean = true,
    val showToDefenderCountry: Boolean = true,
    val cacheDuration: Long = 30L
)

data class BossBarDisplayInfo(
    val country: Country,
    val attackerCountry: Country?,
    val lastUpdateTime: Long = System.currentTimeMillis()
)
```

#### 核心方法改进
```kotlin
/**
 * 更新 BossBar 显示逻辑
 * @param country 被攻击的国家
 * @param attackerCountry 攻击者国家（可选）
 */
fun updateBossBar(country: Country, attackerCountry: Country? = null)

/**
 * 获取应该显示 BossBar 的玩家列表
 * @param country 被攻击的国家
 * @param attackerCountry 攻击者国家
 * @return 玩家列表
 */
private fun getDisplayPlayers(country: Country, attackerCountry: Country?): List<Player>

/**
 * 检查是否应该显示 BossBar
 * @param country 被攻击的国家
 * @param attackerCountry 攻击者国家
 * @return 是否显示
 */
private fun shouldDisplayBossBar(country: Country, attackerCountry: Country?): Boolean
```

### 3. 异步处理机制
```kotlin
/**
 * 异步更新 BossBar
 */
private fun updateBossBarAsync(country: Country, attackerCountry: Country?) {
    Bukkit.getScheduler().runTaskAsynchronously(Guozhan.instance) {
        val players = getDisplayPlayers(country, attackerCountry)
        
        Bukkit.getScheduler().runTask(Guozhan.instance) {
            updateBossBarSync(country, players)
        }
    }
}
```
