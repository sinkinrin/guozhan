# GuoZhan插件集成测试计划

## 📋 测试概述

本文档描述了GuoZhan插件的集成测试计划，涵盖需要真实服务器环境的功能测试。这些测试需要人工执行，因为它们涉及多玩家交互、Folia多线程环境和复杂的游戏机制。

## 🎯 测试目标

- 验证插件在真实Folia环境中的稳定性
- 测试多玩家场景下的功能正确性
- 验证配置系统的实际效果
- 确保Folia多线程环境下的并发安全性

## 🏗️ 测试环境要求

### 基础环境
- **服务器**: Folia 1.21.5+
- **Java**: OpenJDK 21+
- **内存**: 最少2GB RAM
- **测试玩家**: 至少3个测试账号

### 依赖插件
- PlaceholderAPI 2.11.6+
- ProtocolLib 5.3.0+
- squaremap 1.3.6+
- 权限插件（推荐LuckPerms）

### 数据库
- 测试环境：SQLite（默认）
- 生产环境：MySQL 8.0+

## 🔧 故障排除指南

### 常见问题
1. **插件加载失败**
   - 检查Java版本
   - 验证依赖插件
   - 查看控制台错误

2. **数据库连接问题**
   - 检查配置文件
   - 验证数据库权限
   - 查看连接池状态

3. **权限系统问题**
   - 检查权限插件配置
   - 验证权限节点
   - 测试权限继承

4. **Folia兼容性问题**
   - 检查调度器使用
   - 验证线程安全性
   - 查看区域化处理
