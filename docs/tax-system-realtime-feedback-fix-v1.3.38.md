## 🔧 **实现方案**

### **核心功能实现**

#### **1. EconomyBossBarManager增强** ✅
**文件**: `src/main/kotlin/cn/lcofficial/guozhan/manager/EconomyBossBarManager.kt`

**新增功能**:
- 🔧 **TaxIncomeHighlight数据类**: 记录税收收入增量和时间戳
- 🔧 **recentTaxIncome缓存**: 存储最近5秒内的税收收入
- 🔧 **formatEconomyTitleWithTaxHighlight()**: 格式化带税收高亮的BossBar标题
- 🔧 **recordTaxIncome()**: 记录税收收入并触发BossBar立即更新

**显示效果**:
```
正常显示: 国家名 | ⚜1000 (+10/min) ◆500 (+5/min) ⚡800
税收时显示: 国家名 | ⚜1000 (+10/min) ◆500 (+5/min) ⚡800 | 💰税收: +100⚜ +10◆ (3s)
```

**视觉反馈**:
- 税收收入时BossBar颜色变为蓝色（BarColor.BLUE）
- 显示具体的金锭和钻石收入增量
- 显示剩余高亮时间（倒计时）
- 5秒后自动恢复正常显示

#### **2. TaxCollectionTask集成** ✅
**文件**: `src/main/kotlin/cn/lcofficial/guozhan/task/TaxCollectionTask.kt`

**修改内容**:
- 🔧 在税收收取成功后调用 `EconomyBossBarManager.recordTaxIncome()`
- 🔧 支持自动税收和手动税收两种场景
- 🔧 确保Folia线程安全（在主线程中调用BossBar更新）

## 🔍 **税率持久化问题说明**

### **当前状态**
- ❌ **CountryManager.kt**: taxRate字段加载/保存代码被用户移除
- ✅ **数据库字段**: tax_rate字段已存在
- ✅ **EconomyManager**: getTaxRate()和setTaxRate()已修复

### **影响**
- 税率设置后重启服务器会重置为默认值10%
- 不影响税收BossBar实时反馈功能

### **解决方案**
如需恢复税率持久化，需要在CountryManager.kt中恢复以下代码：
1. 构造函数中添加 `row[Countries.taxRate]`
2. save()方法中添加 `it[Countries.taxRate] = taxRate`
