# GuoZhan 插件依赖说明

## 📦 依赖管理

GuoZhan 插件使用 Gradle 构建系统，所有依赖库都已打包到插件 jar 文件中，无需单独安装外部依赖。

---

## 🔧 服务端依赖

### 必需依赖

1. **Folia 1.21.5+**
   - **下载地址**: https://papermc.io/downloads/folia
   - **说明**: GuoZhan 专为 Folia 多线程服务端设计，不支持 Paper/Spigot
   - **版本要求**: 1.21.5 或更高版本

2. **Java 21+**
   - **说明**: Folia 1.21.5 要求 Java 21 或更高版本
   - **推荐**: Oracle JDK 21 或 OpenJDK 21

### 插件依赖

1. **PlaceholderAPI**
   - **下载地址**: https://www.spigotmc.org/resources/placeholderapi.6245/
   - **版本要求**: 2.11.0+
   - **说明**: 提供变量占位符功能，用于显示国家信息

2. **squaremap**
   - **下载地址**: https://github.com/jpenilla/squaremap
   - **版本要求**: 1.2.0+
   - **说明**: 提供网页地图功能，显示国家领土

3. **ProtocolLib**（可选）
   - **下载地址**: https://www.spigotmc.org/resources/protocollib.1997/
   - **版本要求**: 5.0.0+
   - **说明**: 提供数据包处理功能，增强某些特性

## 🚀 安装顺序

### 1. 服务端准备
```bash
# 1. 安装 Java 21
java -version  # 确认版本

# 2. 下载 Folia 1.21.5
wget https://api.papermc.io/v2/projects/folia/versions/1.21.5/builds/12/downloads/folia-1.21.5-12.jar

# 3. 启动服务器（首次启动会生成文件）
java -Xmx4G -Xms2G -XX:+UseG1GC -jar folia-1.21.5-12.jar --nogui
```

### 2. 插件依赖安装
```bash
# 1. 下载并安装 PlaceholderAPI
# 放置到 plugins/ 目录

# 2. 下载并安装 squaremap
# 放置到 plugins/ 目录

# 3. （可选）下载并安装 ProtocolLib
# 放置到 plugins/ 目录
```

### 3. GuoZhan 插件安装
```bash
# 复制 GuoZhan 插件
cp Guozhan-1.0-SNAPSHOT.jar plugins/

# 复制配置文件
cp config-production.yml plugins/Guozhan/config.yml
# 或
cp config-test.yml plugins/Guozhan/config.yml
```

## ⚠️ 兼容性说明

### 支持的服务端
- ✅ **Folia 1.21.5+** - 完全支持
- ❌ **Paper** - 不支持（缺少 Folia 特有的线程调度器）
- ❌ **Spigot** - 不支持
- ❌ **Bukkit** - 不支持
- ❌ **CraftBukkit** - 不支持

### 支持的 Minecraft 版本
- ✅ **1.21.5** - 完全支持
- ⚠️ **1.21.x** - 可能支持（未测试）
- ❌ **1.20.x 及以下** - 不支持

### Java 版本要求
- ✅ **Java 21** - 推荐
- ✅ **Java 22+** - 支持
- ❌ **Java 17 及以下** - 不支持

## 🛠️ 故障排除

### 常见依赖问题

1. **"不支持的服务端"错误**
   ```
   解决方案: 确保使用 Folia 而非 Paper/Spigot
   ```

2. **"PlaceholderAPI 未找到"错误**
   ```
   解决方案: 下载并安装 PlaceholderAPI 插件
   ```

3. **"squaremap 集成失败"警告**
   ```
   解决方案: 下载并安装 squaremap 插件
   ```

4. **Java 版本错误**
   ```
   解决方案: 升级到 Java 21 或更高版本
   ```

### 依赖版本冲突

如果遇到依赖版本冲突：

1. **检查插件版本**
   ```bash
   /plugins
   ```

2. **更新到推荐版本**
   - PlaceholderAPI: 2.11.0+
   - squaremap: 1.2.0+
   - ProtocolLib: 5.0.0+

3. **清理旧版本**
   ```bash
   # 删除旧版本插件文件
   rm plugins/PlaceholderAPI-old.jar
   ```
