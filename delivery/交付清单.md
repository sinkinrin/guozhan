## 🔧 技术规格

### 运行环境要求
- **服务端**: Folia 1.21.5 或更高版本
- **Java**: 21 或更高版本
- **内存**: 建议 4GB 以上
- **存储**: 至少 100MB 可用空间

### 必需依赖
- **PlaceholderAPI**: 2.11.0+
- **squaremap**: 1.2.0+

### 可选依赖
- **ProtocolLib**: 5.0.0+

### 数据库支持
- **SQLite**: 默认，无需配置
- **MySQL**: 可选，需要配置连接信息

## 📋 部署建议

### 测试环境部署
1. 使用 `config-test.yml` 配置
2. 启用测试环境功能
3. 便于功能验证和调试

### 正式环境部署
1. 使用 `config-production.yml` 配置
2. 禁用测试环境功能
3. 确保游戏平衡和稳定性

### 迁移路径
```
开发测试 → 内测服务器 → 公测服务器 → 正式服务器
   ↓           ↓           ↓           ↓
测试配置    测试配置    正式配置    正式配置
```

## ⚠️ 重要提醒

### 部署前检查
- [ ] 确认服务端为 Folia（不是 Paper/Spigot）
- [ ] 确认 Java 版本为 21+
- [ ] 安装必需的依赖插件
- [ ] 选择正确的配置文件版本
- [ ] 备份现有数据（如有）

### 配置关键点
- **测试环境**: `test-environment.enabled: true`
- **正式环境**: `test-environment.enabled: false`
- **数据库**: 默认 SQLite，可选 MySQL
- **资源发放**: 仅测试环境启用

### 监控要点
- 服务器 TPS 稳定性
- 内存使用情况
- 数据库文件大小
- 插件错误日志
