# GuoZhan 常见问题解答 (FAQ)

## 🎮 玩家常见问题

### 基础操作问题

**Q1: 如何创建国家？**
A: 使用命令 `/u create <国家名称>`，需要准备64个铁锭作为建国成本。国家名称长度为3-12个字符，支持中文、英文和数字。

**Q2: 为什么我无法占领领土？**
A: 可能的原因：
- 没有足够的铁锭（需要3个）
- 领土不与现有领土接壤
- 目标领土已被其他国家占领且开启了护盾
- 没有占领权限（需要大臣或君主等级）

**Q3: 如何退出国家？**
A: 使用命令 `/u leave`，注意有1小时的冷却时间。君主无法直接退出，需要先转让君主之位。

**Q4: 忠诚度是什么？如何提升？**
A: 忠诚度反映领土的稳定性，范围0-100。孤立的领土（不与其他领土接壤）会逐渐失去忠诚度。提升方法：
- 确保领土连通性
- 使用 `/u restore` 命令恢复（消耗金币）

### 经济系统问题

**Q5: 如何获得金币和钻石？**
A: 获得方式：
- **金币**: 领土税收、玩家贡献
- **钻石**: 玩家贡献、挖掘获得
- **铁锭**: 挖掘获得

**Q6: 贡献系统的冷却时间是多久？**
A: 向国库贡献资源有24小时的冷却时间。可以使用 `/u contribute` 查看剩余冷却时间。

**Q7: 税收是如何计算的？**
A: 税收基于以下因素：
- 领土位置（越靠近出生点税收越高）
- 领土忠诚度（忠诚度越高税收越多）
- 领土资源类型
- 国家税率设置

### 战争和外交问题

**Q8: 什么时候可以参与王战？**
A: 王战时间为每周六19:20-22:00。在此期间可以攻击敌国核心，平时无法对核心造成伤害。

**Q9: 护盾系统如何使用？**
A: 使用 `/u shield on <小时数>` 激活护盾。护盾限制：
- 成员数量要求
- 30分钟冷却时间
- 领土长宽比不超过2:1
- 基于领土收入的成本
- 王战时间无法激活

**Q10: 如何建立外交关系？**
A: 使用 `/u diplomacy <国家名> <关系类型>`。关系类型包括：中立、友好、同盟、敌对、战争。关系变更有1小时冷却时间。

### 科技系统问题

**Q11: 如何研究科技？**
A: 使用 `/u tech` 打开科技菜单，选择要研究的科技。需要满足前置科技要求和资源成本。

**Q12: 科技效果如何生效？**
A: 科技效果会自动应用到国家所有成员：
- 药水效果：持续性增益
- 属性修改：永久属性提升
- 被动加成：特殊能力

## 🛠️ 管理员常见问题

### 安装和配置问题

**Q13: 插件无法启动，显示红色状态？**
A: 检查以下项目：
1. 确认使用Folia服务器（不是Paper/Spigot）
2. Java版本是否为21或更高
3. 配置文件语法是否正确
4. 数据库连接是否正常

**Q14: 数据库连接失败怎么办？**
A: 解决步骤：
1. 检查数据库服务是否运行
2. 验证config.yml中的数据库配置
3. 确认数据库用户权限
4. 测试网络连接

**Q15: 如何从SQLite迁移到MySQL？**
A: 迁移步骤：
1. 备份现有SQLite数据
2. 创建MySQL数据库和用户
3. 修改config.yml数据库配置
4. 重启服务器（插件会自动创建表结构）
5. 手动迁移重要数据（如有需要）

### 性能和维护问题

**Q16: 服务器出现卡顿怎么办？**
A: 优化建议：
1. 启用调试模式监控性能
2. 调整数据库连接池大小
3. 优化BossBar更新频率
4. 清理过期缓存数据
5. 检查其他插件冲突

**Q17: 如何备份GuoZhan数据？**
A: 备份内容：
- 数据库：`mysqldump -u username -p guozhan > backup.sql`
- 配置文件：复制 `plugins/GuoZhan/` 整个目录
- 玩家数据：包含在数据库备份中

**Q18: 如何清理测试数据？**
A: 使用GM命令：
```bash
/gzgm cleardata countries    # 清理国家数据
/gzgm cleardata territories  # 清理领土数据
/gzgm cleardata all         # 清理所有数据
/gzgm cleardb confirm       # 完全重置数据库（危险）
```

### 权限和安全问题

**Q19: 玩家无法执行命令？**
A: 检查项目：
1. 权限插件是否正确安装
2. 权限节点是否正确配置
3. 玩家是否在正确的权限组
4. 使用 `/gzgm info <玩家名>` 检查玩家状态

**Q20: 如何设置管理员权限？**
A: 权限配置：
```yaml
# 完整管理员权限
guozhan.admin.*: true

# 或者细分权限
guozhan.admin.use: true
guozhan.admin.give: true
guozhan.admin.economy: true
```

## 🔧 技术问题

### 兼容性问题

**Q21: GuoZhan与其他插件冲突怎么办？**
A: 常见冲突和解决方案：
- **领地插件**: 确保GuoZhan的领土系统优先级更高
- **经济插件**: 检查货币系统是否冲突
- **权限插件**: 验证权限节点没有重叠
- **地图插件**: 确保地图渲染不冲突

**Q22: 支持哪些Minecraft版本？**
A: 
- **服务器**: Folia 1.21.5+
- **客户端**: Minecraft 1.21+
- **Java**: Java 21+

**Q23: 可以在Paper/Spigot上运行吗？**
A: 不可以。GuoZhan专为Folia设计，使用了Folia特有的多线程调度器。在Paper/Spigot上会出现兼容性问题。

### 数据问题

**Q24: 玩家数据丢失怎么办？**
A: 恢复步骤：
1. 检查数据库备份
2. 使用GM命令手动恢复：
   ```bash
   /gzgm setcountry <玩家> <国家>
   /gzgm setrank <玩家> <等级>
   ```
3. 如果有完整备份，可以恢复整个数据库

**Q25: 国家数据异常如何修复？**
A: 使用数据完整性检查：
1. 重启服务器（自动执行完整性检查）
2. 查看控制台日志了解修复情况
3. 手动使用GM命令修复特定问题

A: 更新步骤：

2. 下载新版本插件
3. 停止服务器
