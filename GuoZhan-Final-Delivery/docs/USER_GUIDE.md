# GuoZhan 玩家使用手册

## 🎮 快速入门

欢迎来到GuoZhan国战世界！本指南将帮助您快速上手，建立自己的国家并参与激动人心的国战。

### 🏛️ 创建您的第一个国家

1. **准备建国资源**
   - 收集64个铁锭作为建国成本
   - 选择一个合适的位置作为首都

2. **创建国家**
   ```
   /u create <国家名称>
   ```
   - 国家名称长度：3-12个字符
   - 支持中文、英文和数字
   - 名称不能与现有国家重复

3. **成功建国后**
   - 您将自动成为国家的君主
   - 当前位置将成为国家首都
   - 周围3x3区块将自动被占领

## 🗺️ 领土管理系统

### 占领领土

**自动占领模式**（默认）
```
/u claim
```
- 占领当前脚下的区块
- 消耗3个铁锭
- 必须与现有领土接壤

**手动占领模式**
```
/u claimmode        # 切换到手动模式
```
- 手持木斧右键点击方块占领
- 更精确的领土控制
- 适合规划领土边界

### 领土管理命令

```bash
/u unclaim          # 放弃当前区块（首都除外）
/u map              # 获取15x15疆域地图
/u harvest          # 收获领土资源
/u claimmode        # 切换占领模式（自动/手动）
```

### 领土忠诚度系统

- **忠诚度范围**: 0-100
- **影响因素**: 领土是否与其他领土接壤
- **衰减机制**: 孤立的领土忠诚度会逐渐下降
- **后果**: 忠诚度为0的领土会自动失去

**提升忠诚度方法**:
1. 确保领土与其他领土接壤
2. 使用 `/u restore` 命令恢复所有领土忠诚度（消耗金币）

## 👥 国家成员管理

### 邀请和管理成员

**邀请玩家**
```
/u invite <玩家名>   # 邀请玩家加入国家
```

**接受邀请**（被邀请的玩家使用）
```
/u accept           # 接受邀请
/u decline          # 拒绝邀请
```

**成员管理**（君主和大臣可用）
```
/u kick <玩家名>     # 驱逐成员
/u promote <玩家名>  # 提升为大臣
/u demote <玩家名>   # 降级为国民
/u title <玩家名> <头衔>  # 设置自定义头衔
```

**权力转移**（仅君主可用）
```
/u transfer <玩家名> # 将君主之位转让给指定玩家
```

### 成员等级系统

| 等级 | 权限 | 能力 |
|------|------|------|
| 君主 | 最高权限 | 所有管理功能 |
| 大臣 | 管理权限 | 邀请、踢人、占领领土 |
| 国民 | 基础权限 | 在领土内建设、使用设施 |

## 💰 经济系统

### 国库管理

**查看国库**
```
/u treasury         # 查看国家金库状态
```

**向国库贡献**
```
/u contribute <资源类型> <数量>
```
- 支持的资源：gold（金锭）、diamond（钻石）
- 24小时冷却时间
- 贡献会增加国家资源

**税收系统**
- 国家会自动从领土收取税收
- 税收基于领土位置和资源类型
- 越靠近出生点的领土税收越高

### 资源类型

| 资源类型 | 获取方式 | 用途 |
|----------|----------|------|
| 金币 | 税收、贡献 | 科技研究、护盾激活 |
| 钻石 | 贡献、挖掘 | 高级科技、特殊功能 |
| 铁锭 | 挖掘 | 占领领土、基础建设 |

## 🤝 外交系统

### 外交关系类型

| 关系类型 | 效果 | 特点 |
|----------|------|------|
| 中立 | 无特殊效果 | 默认关系 |
| 友好 | 减少意外伤害 | 和平共处 |
| 同盟 | 互相保护 | 战略合作 |
| 敌对 | 增加伤害 | 竞争关系 |
| 战争 | 大幅增加伤害 | 全面对抗 |

### 外交命令

```bash
/u diplomacy <国家名> <关系类型>  # 设置外交关系
/u diplomacy list                # 查看所有外交关系
```

**注意事项**:
- 关系变更有1小时冷却时间
- 战争状态下可以攻击对方核心
- 同盟国家可以互相支援

## ⚔️ 战争系统

### 王战时间

- **时间**: 每周六 19:20-22:00
- **准备阶段**: 19:00-19:20
- **战争阶段**: 19:20-22:00

### 战争机制

**核心攻击**
- 在王战时间内可以攻击敌国核心
- 核心血量降至0则国家被摧毁
- 攻击核心需要在敌国领土内

**战争奖励**
- 击杀敌国玩家获得经济点数
- 摧毁敌国核心获得大量奖励
- 战争胜利提升国家声望

### 防御机制

**护盾系统**
```
/u shield on <小时数>   # 激活护盾
/u shield off           # 关闭护盾
```

**护盾限制**:
- 成员数量要求
- 30分钟冷却时间
- 领土长宽比限制（2:1）
- 基于领土收入的成本
- 王战时间段限制

## 🎯 进阶策略

### 建国选址建议

1. **远离出生点**: 避免新手干扰
2. **资源丰富**: 选择矿物资源丰富的区域
3. **地形优势**: 利用自然屏障防御
4. **扩张空间**: 确保有足够的发展空间

### 领土扩张策略

1. **优先占领高价值区域**: 靠近出生点的领土税收更高
2. **保持领土连通性**: 避免孤立的领土
3. **建立防御线**: 在边境建立防御工事
4. **资源点控制**: 占领重要的资源产出点

### 外交策略

1. **建立同盟**: 与邻国建立友好关系
2. **制衡强国**: 防止某个国家过于强大
3. **资源互补**: 与资源互补的国家合作
4. **情报收集**: 了解其他国家的实力和动向

### 战争准备

1. **科技发展**: 优先研究军事科技
2. **资源储备**: 积累足够的战争资源
3. **防御建设**: 加强核心区域防御
4. **盟友协调**: 与盟友制定作战计划

## ⚠️ 注意事项

### 游戏规则

1. **禁止使用外挂**: 违者将被封禁
2. **文明游戏**: 禁止恶意破坏和骚扰
3. **公平竞争**: 禁止利用bug获取优势
4. **尊重他人**: 保持良好的游戏环境

### 常见问题

**Q: 如何退出国家？**
A: 使用 `/u leave` 命令，有1小时冷却时间。

**Q: 国家被摧毁后怎么办？**
A: 可以重新创建国家，或加入其他国家。

**Q: 如何恢复领土忠诚度？**
A: 使用 `/u restore` 命令，需要消耗金币。

**Q: 护盾什么时候不能使用？**
A: 王战时间段内无法激活护盾。
